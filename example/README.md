# example — a real bundle

`ilyamiro/imperative-dots` is installed like this:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/ilyamiro/imperative-dots/master/install.sh)"
```

That `install.sh` is **1898 lines of bash**. It hardcodes a 68-package array at
line 157, bootstraps `yay` if no helper exists, runs `pacman -Sy`, clones a
wallpaper repo, `chsh`es the user to zsh, enables root services, and reports
usage to a telemetry endpoint. To read what it will do to your machine you have
to read all 1898 lines.

This directory is the same rice as a **bundle**: one manifest plus the config
tree. It was collected from a real machine running that rice after
customization, so the lists are what is actually installed — not what upstream
ships.

| | install.sh | dotfiles.toml |
|---|---|---|
| Lines to read | 1898 | 72 |
| Package list | array at line 157 | `[packages]` |
| What each package is for | — | `[components]` |
| Root services | enabled with sudo | not permitted; a hook you read first |
| Runs arbitrary code | yes, immediately | only hooks, shown before they run |
| Telemetry | yes | no |

## What's in here

```
example/
├── dotfiles.toml     # the manifest
└── config/
    ├── hypr/         # hyprland.conf, config/*.conf, templates/, scripts/*.sh
    ├── kitty/        # kitty.conf + catppuccin.conf (kitty.conf includes it)
    └── swayosd/      # style.css, referenced by autostart.conf
```

`config/hypr/scripts/` keeps its executable bits — 14 of them. That is the
invariant behind `fs::copy` in `apply.rs`; losing one breaks the rice silently.

## What was left out, and why

- **`scripts/quickshell/`** — the rice's own QML UI, 27 MB, of which 23 MB is
  `guide/previews/*.png`. Preview media is dead weight at install time; this is
  the case `docs/real-world.md` F8 describes, found again in a live rice.
- **`config/fish/`** — personal aliases, not part of the rice.
- **`settings.json`** — autogenerated by the quickshell settings UI, so it is in
  `ignore` rather than in the tree.

**`config/monitors.conf` stays in.** It is machine-specific and it was in `ignore`
at first, which was wrong: `hyprland.conf` sources it unconditionally, so leaving
it out hands the receiver a config error instead of a rice. It ships with this
machine's two monitors in it — **edit it after installing.** `ignore` is a
collect-time filter, not an install-time one; a directory link has no per-file
granularity to skip anything with. `docs/design.md` §7.

So this is a real bundle, deliberately trimmed. When `collect` exists it will
produce this directory instead of it being assembled by hand.

## What the collection turned up

Four things the design had assumed away, found on a real machine.

**1–3: `pacman -Qoq` returns nothing for three components.** `starship` sits in
`/usr/local/bin` (its own curl script put it there), the terminal font is in
`~/.local/share/fonts/CascadiaMono/` and the cursor theme in
`~/.local/share/icons/Bibata-Modern-Ice`. All three were hand-installed.

The first conclusion was "no package owns them, so ship the files or declare a
`url`". That was wrong for two of the three:

```
$ pacman -Ss '^starship$'   → extra/starship 1.26.0-1
$ pacman -Ss cascadia       → extra/ttf-cascadia-mono-nerd 3.5.1-1
```

`-Qoq` answers *which package installed this file* and correctly says nobody.
The useful question is *which package could provide it*, and `pacman -F` on the
basename answers it. Both are now plain entries in `[packages]`, which is how the
receiver should get them — not 40 MB of `.ttf` in the repo and not a link to a
release page. Only the cursor keeps its `url`: nothing in the repos ships it, and
a `url` means **"install this yourself"**, printed in the summary, never fetched.

**4: `kitty.conf` ends with `include ~/.config/kitty/catppuccin.conf`, and this
directory did not ship that file.** Hand-assembled, one file forgotten out of
four — the bundle installed a kitty that errors on every start and has none of
the rice's colours. Nothing caught it, because reference following was specified
for WM configs only and kitty is not a WM. It is a general rule now
(`docs/design.md` §5.1), and the file is here.

**5: running that rule by hand over the rest of this directory found nine more
dangling references**, one from each category §5.1 defines. Worth listing,
because together they are the argument for the check existing:

| Reference | Category | What happened |
|---|---|---|
| `~/.config/swayosd/style.css` — `autostart.conf:12` | not selected | a real miss; `config/swayosd/` was not collected at all though `swayosd-git` is in `[packages]`. **Now shipped.** |
| `~/.config/hypr/settings.json` — `workspaces.sh:40` | ignored on purpose | fine, and the reason is visible on the line above it: `# fallback to 8`. The consumer tolerates absence, which is what makes a generated file safe to `ignore` |
| `~/.config/hypr/scripts/weather.sh` — `settings_watcher.sh:5` | **dead** | it does not exist on the source machine either. Upstream's script references a file that was never there — the bundle inherited a bug rather than created one |
| `~/.config/hypr/scripts/quickshell/…` ×6 | not selected, deliberately | see below |

**The quickshell hole is the honest one.** `scripts/quickshell/` is the rice's
entire UI — bar, launcher, lock screen, screenshot overlay — and it was left out
because the directory is 27 MB. So `lock.sh`, `screenshot.sh` and `qs_manager.sh`
ship here and call into nothing. As a bundle this one is **incomplete, and it now
says so** instead of looking finished.

The fix is the thing `ignore` is actually for: 23 MB of those 27 are
`guide/previews/*.png`. **Without them the shell is 3.9 MB.**

```toml
ignore = ["config/hypr/scripts/quickshell/guide/**"]
```

That is `ignore` doing its real job — dropping dead weight on the way in, not
trying to skip a file at install time. Left undone here as a deliberate call about
what belongs in *this* repo, not because the bundle is better without it.

**6: `quickshell-git` was in `[packages]`, and no such package exists.** Not in any
repo, not installed on the source machine. `pacman -Qoq $(command -v quickshell)`
names the real provider in one call. A hand-written manifest guessed a plausible
name and nothing checked it — `collect` would not have. It is `quickshell` now.

## What this bundle still needs

The project's acceptance test is *"this installs the rice without `install.sh`"*
(`TODO.md`). The tool is not written yet, but the bundle's own gaps are known and
independent of it:

| Missing | Why it matters | Blocked on |
|---|---|---|
| `config/hypr/scripts/quickshell/` | bar, launcher, lock screen, screenshot overlay — the whole UI | a call about 3.9 MB in this repo |
| `hooks/post-install.sh` | root services (`NetworkManager`, `sddm`, `power-profiles-daemon`, `swayosd-libinput-backend`) and `chsh` to fish. A manifest may not do these; a hook the user reads first may | nothing — it can be written now |
| `assets/wallpapers/` + an `[[assets]]` entry | `install.sh` clones a wallpaper repo; `awww` starts with nothing to show | picking which wallpapers ship |
| `config/hypr/config/monitors.conf` | ships with this machine's two monitors — edit after installing | v1 has no templates (`design.md` §7) |
| `scripts/weather.sh` | `settings_watcher.sh` calls it; it does not exist upstream either | upstream, not us |

Everything above is bundle *content*. Nothing on this list needs a format change,
which is the useful part: the manifest already has a field for each one.
